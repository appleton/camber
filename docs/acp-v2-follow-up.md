# ACP v2 follow-up for async transcript updates

As of November 27, 2026, ACP v2 is in Preview and its wire format can still change. The TypeScript SDK exposes an experimental v2 entry point. Recent Claude and Codex adapters ship v2 support. Camber currently uses ACP v1. [Preview rollout](https://github.com/agentclientprotocol/agent-client-protocol/pull/2961) · [Schema beta.4](https://github.com/agentclientprotocol/agent-client-protocol/releases/tag/schema-v2.0.0-beta.4) · [Claude adapter](https://github.com/agentclientprotocol/claude-agent-acp/releases) · [Codex adapter](https://github.com/agentclientprotocol/codex-acp/releases)

In v1, Camber records completion when the agent returns from `session/prompt`. In a live transcript, folding stops at that boundary and keeps any unsolicited follow-up replies visible between tool runs. In v2, the prompt response acknowledges input. A `state_update` transition to `idle` ends foreground work, and a new `running` interval can start when the agent follows up on a background result. Background tool updates can also arrive while the session stays idle. [V1 prompt completion](https://agentclientprotocol.com/protocol/v1/prompt-turn#4-check-for-completion) · [V2 foreground and background work](https://agentclientprotocol.com/protocol/v2/prompt-lifecycle#foreground-and-background-work)

Start with an opt-in pilot on Claude and Codex. Negotiate per connection and keep v1 available. Update the helper and UI to track foreground state independently of prompt acceptance. Exercise async follow-ups, late tool updates, cancellation, steering, and resume with both adapters before making v2 the default. [Migration guide](https://agentclientprotocol.com/protocol/v2/migration)

To preserve completed replies after reopening a chat, Camber also needs to store the boundaries it observes live. V1 history replay does not repeat prompt responses, and v2 replay excludes historical foreground state updates. [V1 replay](https://agentclientprotocol.com/protocol/v1/session-setup#loading-a-session) · [V2 replay](https://agentclientprotocol.com/protocol/v2/session-setup#replay-contents)
